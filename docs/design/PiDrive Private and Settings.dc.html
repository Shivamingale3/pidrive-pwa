MODEL AS BUILT
Password = your account on the Pi
PIN = app gate, asked again for private
Everything is stored on the Pi — Postgres and MinIO
The app is a thin client over the API
No sign-up — admin adds users by API
The private area keeps its own tree, shows no trace in Media, search or recents, and relocks on leaving the app. There is no pairing screen: the server address ships with the build and appears read-only in About.
